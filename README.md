# Телесуфлёр для Mac — готовые сборки

Здесь лежат только собранные версии приложения «Телесуфлёр» для macOS и файл,
по которому установленное приложение узнаёт о новой версии. Исходного кода здесь нет.

## Установка

1. Открой [последний выпуск](https://github.com/mynzhanov/teleprompter-releases/releases/latest)
   и скачай `Teleprompter-Mac.zip`.
2. Распакуй и следуй файлу «Как установить.txt» из архива.

Нужна macOS 14 или новее (Apple Silicon или Intel).

## Обновление

Установленный Телесуфлёр сам проверяет новые версии и предлагает обновиться
кнопкой в окне приложения. Обновление ставится только если оно подписано ключом
разработчика; о тебе и о твоём тексте приложение ничего не передаёт.
